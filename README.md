# EGestión Site Build

# PROJECT: EGestión — Marketing website (Spanish site, built in Lovable)

Build a professional, modern, concise one-page marketing website (with anchor

navigation) for EGestión, an accounting + strategic advisory firm based in

Los Andes, Chile (Valle de Aconcagua). The site must be in SPANISH. All UI copy

below is provided in Spanish — use it verbatim, do not translate or paraphrase.

I am uploading the brand assets: logo files, the color palette, and the full

brand identity document. Respect them strictly. Where this prompt and the brand

doc overlap, both agree — follow them.

## GOAL / TONE

The site should feel: professional, trustworthy, warm, easy to understand,

modern (startup/consulting-partner aesthetic), and above all it should drive

the visitor to WANT to book a meeting. Keep it SHORT and clean — not a long,

heavy, over-animated site. Low interactivity: subtle hover states and a gentle

fade-in-on-scroll only.

Positioning to convey (do NOT print this as copy, it's direction):

"EGestión is the strategic partner that sits down with you. Senior-accountant

experience with the closeness of a business partner — accounting, taxes,

finance, people and decisions, face to face." The FLAGSHIP service is TAX

ADVISORY ("asesoría y consultoría tributaria") — it must appear first and with

the most visual weight.

Voice: professional but close, uses "tú", short sentences, human before

corporate, concrete before grandiose. Every technical term explained in plain

language.

## VISUAL IDENTITY (use these EXACT values)

Colors:

- Primary Blue  #0447F3  (main brand color, large blocks, headings, buttons)

- Lime Accent   #CDF22C  (accents, tags/pills, CTA fills, highlight blocks)

- Ink / Black   #0A0A0A  (body text on light backgrounds)

- White         #FFFFFF

- Soft neutral  #F5F6F8  (alternate section backgrounds)

Color rules (accessibility — follow strictly):

- Lime on white FAILS contrast. Never use lime for small text on white.

- On WHITE backgrounds: text is ink/black or blue; lime only as fills/underlines/tags.

- On BLUE (#0447F3) backgrounds: text is white; lime for highlights and CTAs.

- On LIME (#CDF22C) fills: text is blue or black, never white.

- Primary buttons: blue fill / white text, OR lime fill / blue text.

Logos (from the uploaded files):

- Use the horizontal "egestión" wordmark in the header. On light header use the

  blue+dark version; if the header is blue, use the white/green version.

- Use the standalone rounded "eg" mark for the favicon and the mobile logo.

- Tagline that may appear near the logo / hero / footer: "Tu empresa en buenas manos."

Typography:

- Headings: a friendly geometric/rounded sans that matches the logo — use

  "Poppins" (or "Onest" / "Space Grotesk" as alternates). Bold, large, confident.

- Body: "Inter", regular weight, high legibility.

UI style (inspired by the reference moodboard — modern consulting/startup):

- Generous white space, big bold headlines, clear hierarchy.

- Rounded cards (border-radius ~16–20px), soft shadows.

- Pill-shaped buttons and small pill tags/labels above section titles.

- A credibility "stats row" with big numbers.

- Rounded arrow icons (↗) on buttons/cards, like the references.

- Fully responsive, mobile-first. One recurring primary CTA everywhere:

  "Agenda una reunión".

## TECHNICAL NOTES

- Semantic HTML, responsive, mobile-first, fast, accessible (WCAG AA contrast —

  respect the color rules above).

- Smooth-scroll anchor navigation between sections.

- Only subtle animations: hover states + fade-in-on-scroll. No parallax, no

  heavy motion.

- Favicon = the "eg" mark.

- Use placeholder images where photos of René, the office, meetings, and the

  cowork space will go, clearly labeled so they're easy to swap later.

- Contact form: wire it to a simple submission (Formspree-style or console log)

  so it's ready to connect to a real endpoint later.
